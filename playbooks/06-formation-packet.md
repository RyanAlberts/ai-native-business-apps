# Playbook 06 — The Day-0 Formation Packet

**Who works:** the agent, entirely. The founder gets the handoff walk-through at the end.
**Founder time:** ~10 minutes (the walk-through).
**Gate:** `bash verify/journey_gate.sh 06` exits 0.

## Goal

Synthesize the five specialist outputs into ONE coherent, ordered Day-0
Formation Packet, and land the complete artifact set in
`formation-packet/` — the same files the Python CLI produces, so either
path picks up where the other left off.

## The brief (your role for this phase)

Read `PACKET_SYNTHESIS_PROMPT` in
`advanced_business_agents/multi_agent_apps/founding_journey/prompts.py` and
follow it exactly: reconcile, order, and de-duplicate (never just
concatenate), resolve contradictions in the founder's favor and flag them,
and output its exact section structure — Disclaimer, Executive Summary,
Master Day-0 Checklist (in real-world order: entity before EIN, EIN before
bank, 83(b) clock from stock issuance), Key Deadlines table, Links &
Portals, Documents Prepared, What's Next (Days 30–90).

Your input is `company.json` plus the five phase artifacts
(`formation-packet/01-…` through `05-…`). If a phase completed with a gap,
say so in the packet rather than papering over it.

## Artifacts to produce (exact filenames)

| File | How |
|---|---|
| `formation-packet/00-formation-packet.md` | The synthesized packet, disclaimer footer at the end. |
| `formation-packet/00-formation-packet.html` | The same packet as a printable page (founder opens it → Save as PDF). Use the `_HTML_SHELL` template in `core/artifacts.py`: render the packet markdown to clean HTML for `{body}`, title "Day-0 Formation Packet — <company>", and `{meta}` = "Generated by Keel. ⚠️ " + the `DISCLAIMER` from `core/brand.py`. Self-contained — no external assets. |
| `formation-packet/compliance-deadlines.ics` | Deterministic, facts-only — mirror `deadlines_for()` in `advanced_business_agents/multi_agent_apps/founding_journey/journey.py`: the 83(b) postmark deadline (formation/issuance date + 30 days) if there is a real date, and the Delaware March-1 franchise-tax/annual-report deadline if this is a DE corporation (this year's if it hasn't passed — check with `date +%F` — else next year's). Format per `ics_artifact()` in `core/artifacts.py` (calendar name "Keel — Compliance Deadlines", all-day events, CRLF). No computable events → skip the file and say why (the richer calendar lives inside `05-compliance_tax.md`). |
| `formation-packet/company.json` | Copy the final profile from the repo root into the packet folder — it's the portable record of what was decided. |

## Steps

1. Re-read all five artifacts and `company.json`.
2. Synthesize the packet per the brief.
3. Write the four artifacts above.
4. Update `PROGRESS.md`: phase 06 done, date, journey complete — plus any
   gaps that were flagged along the way.
5. Run the gate, then do the handoff (contract → "When you finish"): walk
   the founder through the master checklist and deadlines, say the 83(b)
   postmark date out loud if there is one, list what to sign / mail / file
   / keep, remind them to have a professional review before filing, and
   tell them how to resume later.

## Gate

`bash verify/journey_gate.sh 06` — checks the packet markdown has the
required sections and footer, the HTML is a self-contained printable page,
the profile copy exists, and the `.ics` is well-formed when
`formation_date` makes it required.

## If things go wrong

- **An upstream artifact is missing** (a phase was skipped with a gap):
  synthesize from what exists, mark the gap prominently in the packet's
  checklist ("Banking & insurance step incomplete — re-run Phase 04"), and
  keep the gate honest — if the gap is fatal to the packet's usefulness, go
  back and finish that phase instead of shipping filler.
- **Contradictions between specialists** (e.g. the legal docs assumed a
  different entity than Phase 01 chose): that's a real error, not a
  synthesis footnote. Fix the offending artifact first, then synthesize.
