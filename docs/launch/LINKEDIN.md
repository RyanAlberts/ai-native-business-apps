"who is this for," and a soft CTA. Skip hashtag spam (3–5 max, at the end).
Lead with a hook line, then whitespace — the feed truncates after ~3 lines,
so the first sentence has to earn the "…see more" click.

## Post

I rebuilt Stripe Atlas as an open-source AI agent — and I'm giving it away.

Every founder I know lost a weekend (or $500, or both) to the same Day-0
grind: incorporate, get an EIN, file the 83(b) before the 30-day window
closes forever, draft an operating agreement, open a bank account, figure
out sales-tax nexus, build a compliance calendar.

It's all necessary. None of it is the reason you started a company.

So I built **Keel** — the open-source AI back-office for founders.

You fill in your company once. Five specialist agents run in the right
order — incorporation → 83(b) → legal docs → banking → compliance — and
hand you a complete Day-0 Formation Packet: a printable PDF, the actual
documents, and a calendar file of every deadline.

Three things make it different from the usual "AI for X" demo:

→ It hands you real, ready-to-file files — not a chat transcript.
→ It's "prepare-to-submit," so a human always reviews before anything is
   filed. No black-box auto-filing of your legal docs.
→ It runs on the Claude subscription you already pay for. No API key, no
   SaaS bill, no telemetry. It's Apache-2.0 — fork it, run it for your whole
   accelerator batch, make it yours.

If you're a founder, an operator setting up entities, or you run a program
that onboards new companies, I'd genuinely love your eyes on it — especially
on the parts that touch tax and legal, where being right is the whole point.

Repo + 90-second demo in the comments. ⭐ and honest feedback both help.

## Posting notes
- Native-upload the demo video; put the GitHub link in the FIRST COMMENT.
- Best windows: Tue–Thu, 8–10am in your audience's timezone.
- Reply to every comment in the first 2 hours (early engagement = reach).
- Re-share to relevant LinkedIn groups (founder / accelerator / indie-hacker)
  a day later, not simultaneously.
- A week in: post a follow-up with a concrete result ("N founders ran it,
  here's what broke and what I fixed") — the follow-up often outperforms the
  launch.
